# Peringatan Penting: Data Pembelajaran Anda

Aplikasi ini menyimpan kemajuan belajar Anda (termasuk materi yang telah diselesaikan) di penyimpanan lokal (_local storage_) peramban Anda. Data ini memungkinkan Anda melanjutkan dari titik terakhir Anda berhenti saat menggunakan aplikasi ini.

## Tindakan yang DAPAT MENGHAPUS Data Anda:

⚠️ **Tindakan-tindakan berikut akan menghapus kemajuan belajar Anda:**

1. **Menghapus data penjelajahan/riwayat peramban**
   - Melalui pengaturan peramban: "Clear browsing data"
   - Terutama jika memilih "Cookies and site data" atau "Cached images and files"

2. **Menggunakan mode penyamaran/penjelajahan pribadi (Incognito/Private Mode)**
   - Data tidak akan disimpan saat sesi mode pribadi ditutup

3. **Menghapus penyimpanan situs secara manual**
   - Melalui pengaturan pengembang (Developer Tools) peramban
   - Melalui pengaturan peramban: "Site settings" > "Cookies and site data" > "Manage and delete"

4. **Menginstal ulang atau menghapus peramban**
   - Akan menghapus semua data lokal dari aplikasi web yang diakses

## Tips untuk Mempertahankan Data Pembelajaran Anda:

✅ **Untuk menjaga kemajuan belajar Anda:**
- Hindari membersihkan data penjelajahan secara keseluruhan jika tidak perlu
- Gunakan peramban reguler (bukan mode pribadi) saat belajar
- Jika Anda perlu membersihkan data penjelajahan, saring situs ini dari daftar yang akan dihapus
- Gunakan peramban yang sama untuk konsistensi pengalaman belajar

## Catatan:
- Data disimpan secara lokal di perangkat Anda, bukan di server
- Data tidak akan hilang saat aplikasi diperbarui
- Setiap peramban (Chrome, Firefox, Safari, dll.) memiliki penyimpanan lokal yang terpisah

Terima kasih atas perhatian Anda. Semoga pembelajaran Anda berjalan dengan lancar dan data kemajuan Anda tetap aman.
